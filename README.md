# Python Task Manager API

A RESTful task management API built with Python and FastAPI.

## About

This project is my first portfolio project, created to practice backend development, API design, database integration, and automated testing.

## Features

- [ ] Create tasks
- [ ] List tasks
- [ ] Retrieve a task by ID
- [ ] Update tasks
- [ ] Delete tasks
- [ ] Store tasks in a database
- [ ] Add automated tests

## Technologies

- Python
- FastAPI
- SQLite
- SQLAlchemy
- Pytest
